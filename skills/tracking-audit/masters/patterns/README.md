# Event Pattern Library

`event-patterns.json` ist eine **Entscheidungs-/Strukturbibliothek**, keine Liste automatisch einzurichtender Conversions.

Jedes Pattern wird nur benutzt, wenn der Kundenplan die Semantik und den realen Erfolgs-/Interaktionspunkt verifiziert hat. Insbesondere werden Scroll-, Klick- und Engagement-Events nicht automatisch an Ads/Meta weitergereicht.
