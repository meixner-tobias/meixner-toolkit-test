# Sanitized Production Reference

Diese beiden JSONs sind **sanitisierte Architektur-Referenzen**, keine importfertigen Kunden-Templates:

- `web-reference.sanitized.json` — reales Muster: Web Conversion Linker, Google Tag -> sGTM, GA4 Event-Tags, verschiedene Triggerarten.
- `server-reference.sanitized.json` — reales Muster: GA4 Server Client, Server Conversion Linker, Google Ads Conversion Tags, Stape Meta CAPI Template/Tags.

Alle bekannten Kunden-/Kontowerte und Credentials wurden durch verstaendliche Platzhalter ersetzt. Die Referenzen enthalten bewusst auch beobachtete Entscheidungen, die **nicht automatisch Best Practice fuer jeden Kunden** sind. Die Bewertung steht in `architecture.json`; verbindliche Nutzungsregeln in `../REFERENCE-POLICY.md`.

Originalexporte gehoeren nicht in das Plugin/Repository.
